# ✨ GSAP Animation Master Suite (`/gsap`)

Gunakan perintah `/gsap` untuk menciptakan koreografi animasi web kelas dunia, interaksi scroll storytelling, dan sinkronisasi render loop tanpa jank (60+ FPS).

---

## ⚡ Kemampuan Utama

1. **Official GreenSock Core**:
   - `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, `gsap-plugins` (Flip, Draggable, SplitText).
   - Penanganan siklus hidup framework (`gsap.context()` & `ctx.revert()`) untuk mencegah memory leak di Vue 3 / Nuxt / React.
2. **Creative 3D Bridging**:
   - `threejs-gsap-integration`: Menghubungkan rotasi kamera 3D dengan scroll halaman via `gsap.ticker` tanpa stutter.
   - `cinematic-gsap-lenis-motion-system`: Sistem smooth scroll editorial mewah ala Awwwards Site of the Day.
   - `gsap-scrolltrigger-storytelling`: Storytelling sticky bertahap dan progressive UI reveals.

## 🤝 Kolaborasi dengan Skill Lain

- **`/gsap` + `/threejs`**: Mengendalikan orbit kamera, pergantian chapter pemandangan 3D, dan depth-of-field secara dinamis.
- **`/gsap` + `/motion`**: Memastikan durasi easing, kurva percepatan, dan kepatuhan `prefers-reduced-motion` sesuai standar aksesibilitas.
- **`/gsap` + `/vue`**: Membungkus timeline animasi di dalam `onMounted` dengan pembersihan bersih di `onUnmounted`.
