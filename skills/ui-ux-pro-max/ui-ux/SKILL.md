# 🎨 UI/UX Pro Max Suite (`/ui-ux`)

Gunakan perintah `/ui-ux` untuk merancang antarmuka web modern kelas premium yang memukau (*stunning visual*), berestetika tinggi, dan mematuhi kaidah ergonomi pengalaman pengguna.

---

## ⚡ Kemampuan Utama

1. **Reasoning & Visual Styles**:
   - 192 profil industri & aturan UX spesifik domain.
   - 79 gaya visual siap pakai (*Glassmorphism, Bento Grid, Neumorphism, Dark Modern, Brutalism, Editorial*).
2. **Harmoni Warna & Tipografi**:
   - 192 palet warna berdasarkan psikologi industri (HSL tailoring).
   - 74 pairing Google Fonts modern dengan kontras rasio WCAG AAA.
3. **Mesin Rekomendasi Cerdas**:
   - Skrip pencari lokal Python `search.py` untuk mencocokkan industri dengan stack desain yang ideal.

---

## 🚀 Cara Memanggil di Chat

- `/ui-ux rekomendasikan gaya desain dan palet warna untuk landing page pariwisata Minahasa Selatan`
- `/ui-ux buat layout grid Bento modern untuk menampilkan fitur aplikasi`
- `/ui-ux audit kontras warna dan tipografi halaman ini agar ramah aksesibilitas WCAG`

## 🤝 Kolaborasi dengan Skill Lain

- **`/ui-ux` + `/threejs`**: Menentukan tata letak overlay UI di atas canvas 3D agar teks tetap terbaca tajam dan tidak bertabrakan dengan objek 3D.
- **`/ui-ux` + `/image-3d`**: Memilih tone visual dan palet warna yang harmonis dengan tekstur PBR alami.
- **`/ui-ux` + `/gsap`**: Mengatur hierarki elemen visual sebelum dianimasikan secara bertahap saat di-scroll.
